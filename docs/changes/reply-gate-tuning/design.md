# 自動応答の返答判定の見直し

## Why

自動応答チャンネルでは、メンションの無い発言に返答するかを判定モデル Jev（`typesafe/jev-1.14`）が決める。
返答するのは、返答すべき確率（`noul`）がしきい値 `REPLY_GATE_THRESHOLD`（既定 0.3）以上の発言である。
2026-10-17 の本番のスレッドでは、21 件の判定がすべて返答になり、人どうしの会話や独り言、bot への制止にも bot が割り込んだ。

この会話から、しきい値とは別の原因が三つ読み取れる。

1. bot が毎回返答するので、新しい発言の直前は常に bot の返答になる。判定の問いは「bot の直前の回答への続きの質問」を返答する側の基準に挙げているので、人どうしの会話が続いていても bot への続きとして読まれやすくなる（推測。判定の状態の組み立てと問いの文面から）。
2. 判定の問い（`src/services/replyGateService.ts` の `buildReplyGateQuestion`）の黙る側の基準に、「bot について人どうしで話している発言」と「bot に黙るよう求める発言」が無い。この会話で 0.3 以上になった黙るべき発言の多くは、この二つに当たる。
3. bot は「今後は呼びかけられたときだけ返します」「黙っておきます」と返答したが、返答するかは判定モデルが決めるので、返答を生成するモデルにはその約束を守る手段が無い。実際、その後も返答し続けた。

## 依存 / 関連 change

- 先行（実装済み）: reply-gate（v1.15.0）— 本 change はその判定の問い、状態、しきい値を見直す
- 連携: [author-identity](../author-identity/design.md) — 判定に渡す発言者の名前を、返答と同じ `表示名 (@ユーザー名)` に揃える

## Goals / Non-Goals

**Goals:**

- bot について人どうしで話している発言、bot への制止、独り言に返答しないようにする
- bot が「黙る」と言ったら、その約束を仕組みで守れるようにする
- 判定の変更を、手書きの例と本番から作った例の両方で測れるようにする

**Non-Goals:**

- しきい値の決め直し。2026-10-17 時点の本番の判定は 1 つの会話の 21 件で、参加者は 2 人、話題の多くが bot 自体についての話なので、しきい値を決めるには偏りが大きい。判定のログがたまってから別に行う
- メンションされた発言の扱い。今までどおり必ず返答する

## Decisions

| 判断事項 | 選択 | 理由 |
| -------- | ---- | ---- |
| 判定の問いの黙る側の基準 | 「${botName} について人どうしで話している発言」「${botName} に黙る、口を挟まないよう求める発言」「独り言やメモ」を足す | 原因 2 に当たる発言を、問いの文面で黙る側に寄せる。文面の変更は判定の費用も遅れも変えない |
| bot の約束を守る仕組み | 返答を生成するモデルに `pause_auto_reply` tool を与える。呼ぶと、そのチャンネル（スレッドならそのスレッド）で、メンションの無い発言への返答を指定した分数だけ止める。止めている間は判定も呼ばない | 原因 3 は判定の精度では直らない。判定の状態に bot の過去の返答の文面は入るが、「黙る」という約束を判定モデルが毎回読み取る保証は無い。tool にすると、モデルが約束した時点で仕組みが守る |
| 一時停止の長さ | モデルが 5〜120 分の範囲で指定する。既定は 30 分 | 「今の話題の間は黙って」と「しばらく黙って」の両方に応じられる。上限を置くのは、止めたまま忘れられないようにするためである |
| 一時停止の解除 | 期限が来るか、bot の再起動で解除する。メンションされた発言には、止めている間も返答する | メンションは明示的な呼び出しなので、止めていても答える。期限をメモリに持つだけにして DB に書かないのは、再起動で解除されても困らないからである |
| 判定を複数の問いに分けること | 本 change では行わない。手書きの例と本番から作った例で、上の二つの効果を測った後で検討する | Decisions API は 1 回の呼び出しで複数の問いを受け付ける（`https://openrouter.ai/openapi.json` の `/api/alpha/decisions` の例）。原因 1 に効く見込みがあるが、問いを組み合わせる規則と、問いごとのしきい値を決める根拠がまだ無い。問いが増えたときの費用と遅れも確かめていない |
| 本番の判定を評価の例にすること | 2026-10-17 の 21 件を、人名と文面を言い換えて `scripts/reply-gate-cases.ts` に足す | 手書きの例は作為的で、bot 自体について話す会話が無い。言い換えるのは、利用者の発言をリポジトリに残さないためである |
