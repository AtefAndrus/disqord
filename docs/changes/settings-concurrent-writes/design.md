# ギルド設定の同時変更で変更が消えないようにする

## Why

設定を変える操作が同時に走ると、一方の変更がもう一方に消えていた。
Web 検索の OFF がモデル変更で ON に戻ると、検索ごとの課金が続く。

## Goals / Non-Goals

**Goals:**

- 別の列を変える操作、トグル、自動応答チャンネルの編集が、同時に走っても互いを消さない
- 無料モデル限定の規則が、検証と保存の間に別の操作が入っても破られない

**Non-Goals:**

- すでに検索つきで生成を始めた応答の検索を、Web 検索の OFF で止めること

## Design

実装は PR #132 で入った。
書き込みはリポジトリの `update(guildId, mutate)` に集まり、同期の IMMEDIATE トランザクションの中で、行が無ければ既定値で作り、保存された行を `mutate` に渡し、返された列だけを書く。
トグルとチャンネル編集は保存された行から結果を決め、無料モデル限定の規則は保存時に保存された設定と照らす。
詳細は `src/db/repositories/guildSettings.ts` と `src/services/settingsService.ts` のコメントにある。
